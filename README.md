Para ejecutar nuestro programa te recomendamos tener Visual Studio Code. 
Estos son los pasos a seguir antes de ejecutar nuestro programa:
-Abrir nuestro trabajo en Visual Studio Code.
-Instalar la libreria cryptography poniendo en la terminal: "pip install cryptography".
-Para ver las tablas creadas en la base de datos, pulsar Ctrl + Shift + X y escribir "SQLite Viewer" y descargarlo.

Ahora que ya tienes descargado estas dos cosas, ya puedes ejecutar nuestro programa. 
Lo ejecutas poniendo en la terminal "cd cripto-p1" y a continuación poner "python -m cliente.main" o "python3 -m cliente.main"
